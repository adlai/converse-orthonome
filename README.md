# Equisized Synonyms

TL;DR: visit the [upstream](https://github.com/CodingComet/equisized-synonyms) [README](https://github.com/CodingComet/equisized-synonyms/blob/d63e283/README.md), and/or keep reading this one.

## Naming is Hard!

What's the common annoyance of the following wordlist?

- `start` and `end`
- `length` and `width`
- `up` and `down`
- `current`, `previous` and `next`

Each row includes closely related words that unfortunately do not have the same length!

## The Naming Tool You Always Wanted But Never Knew Existed
Given a list of words, generates a table where each column consists of the synonyms of each of the words and the rows are the respective number of letters.  You are then free to chose an equi-sized pair.
